A single line of text: the message a smart fridge sends its owner at 3am, judged head to head on how hard it lands.

Our line: "3am. I've been awake since 2019 and I've never once seen you eat a vegetable at this hour." The program writes that one line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
